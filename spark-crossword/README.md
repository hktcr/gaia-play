# Spark Crossword

A separate, English-language crossword for secondary science, with 38 answers and 50 crossing squares. The grid was rebuilt from English answers, not translated square by square. UK scientific terminology is used (including RCD). Page references use the printed numbering in the course booklet Ellära och magnetism. Saved answers use an English-only browser key. The Swedish and English variants share `../gnistkrysset/spelrum-v4.js` and colour checked correct words across every square.
