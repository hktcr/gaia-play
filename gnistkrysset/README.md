# Gnistkrysset

Ett fristående övningskryss för ellära och magnetism i NO, årskurs 7–9. **En enkel krets** går att använda under introduktionen; **När magnetismen kommer in** är ett senare repetitionssteg. Upplägget följer ledtrådar och stegvis hjälp i Matens väg/Blodkrysset. Inte ett prov: facit finns i sidans JavaScript och progress visas. Övningen lagrar inga elevuppgifter eller namn och har inga nätverksanrop; svar stannar i webbläsarens lokala lagring.

- Mapp: `gnistkrysset/` i `hktcr/gaia-play`, publicerad av repots befintliga GitHub Pages.
- Redigera `BOARDS` i `kryss.js`: `h` = vågrätt, `v` = lodrätt, positioner börjar vid noll. Svenska bokstäver bevaras.
- Kontroll: `node test.mjs` och prova flödet i webbläsare. Motionsinställningen respekteras. Om GitHub Pages behöver återställas, återställ bara commitens ändringar i denna mapp.
